## 🎯 Development Approach

**1. 문제의 원인을 확인합니다.**
오류를 해결하는 데 그치지 않고
발생 원인과 관련 코드의 동작을 살펴봅니다.

**2. 기술 선택의 이유를 고민합니다.**
일정과 요구사항을 고려하여
구현 가능한 대안들을 비교합니다.

**3. 해결 과정을 기록합니다.**
문제와 해결 방법을 정리하여
다음 개발에서 활용할 수 있도록 합니다.

## 👨‍💻 About Me

안녕하세요! 백엔드 개발자 **노선우**입니다.

저는 새로운 아이디어를 실제 서비스의 기능으로
구현하는 것을 좋아합니다.

개발 중 마주하는 어려움을 단순한 장애가 아니라,
**새로운 기술과 설계를 배울 수 있는 기회**로 생각합니다.

Java와 Spring Boot를 기반으로 백엔드 서비스를 개발해 왔으며,
API 설계, 데이터 처리, AI 서비스 연동에 관심이 있습니다.

- 🔍 **Problem Solving** — 오류의 원인과 데이터 흐름 분석
- 🛠️ **Implementation** — 아이디어를 실제 기능으로 구현
- 🌱 **Learning** — 해결하며 배운 내용을 다음 개발에 활용
- 🤝 **Collaboration** — API 명세 공유와 팀원 간 협업
